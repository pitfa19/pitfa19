# pitfa19

## Intent

Maintain the public pitfa19 GitHub profile README as a concise, accurate index of selected projects.

## Desired outcomes

- Keep project descriptions concise and verifiable against their repositories.
- Provide direct links and minimal setup information where it helps visitors.

## Boundaries

- Keep the profile readable and avoid turning it into full project documentation.
- Link to authoritative project repositories for detailed claims and instructions.
- Require explicit owner approval before pushing public changes.

## Assumptions

The linked project repositories and owner decisions are the authoritative context.
